# Futuristic 3D Portfolio

A mobile-first React portfolio starter with an interactive Three.js hero scene.

## Run locally
1. Install Node.js on a computer or use a browser-based development environment.
2. In the project folder run `npm install`.
3. Run `npm run dev`.

## Deploy
Push the project to a GitHub repository, then import that repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Before publishing
- Replace the initials `SP` and the demo name/text in `src/App.jsx`.
- Replace `hello@example.com` with your own portfolio email.
- Replace placeholder social links with your real profiles.
- Change the concept project descriptions so they accurately describe your own work.
- Test the mobile layout and build logs before sharing the live URL.

## Notes
- The 3D hero can be dragged to rotate; zoom is intentionally disabled.
- This project uses React Three Fiber, Three.js, Drei, Framer Motion and Lucide icons.
- Google Fonts are loaded remotely; the layout has fallbacks if they fail to load.
